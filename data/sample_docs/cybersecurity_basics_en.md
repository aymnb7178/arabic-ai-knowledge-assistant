# Cybersecurity Basics

This short guide covers everyday security habits for students and small teams. It is an original summary written for demonstration purposes.

## Passwords

A strong password is long, unique and hard to guess. Length matters more than complexity, so a passphrase of four or five unrelated words is better than a short string of symbols. Never reuse the same password on different websites, because one leaked password then opens every account.

A password manager stores a different random password for each account, so you only have to remember one master passphrase. Check whether your manager can warn you about passwords that appear in known data breaches.

## Multi-factor authentication

Multi-factor authentication (MFA) asks for a second proof of identity in addition to the password, such as a code from an authenticator app or a hardware security key. Even if an attacker steals your password, they cannot sign in without the second factor. Prefer authenticator apps or security keys over SMS codes, because phone numbers can be hijacked through SIM swapping.

## Phishing

Phishing is a fraud technique where an attacker sends a message that pretends to come from a trusted sender to trick you into clicking a link, opening an attachment or sharing a password. Warning signs include urgent language, an unexpected request for credentials, a sender address that does not match the organisation, and links whose real destination differs from the displayed text. When in doubt, do not click: open the website by typing its address yourself and report the message to your IT team.

## Software updates

Updates fix known security vulnerabilities. Attackers actively scan for computers that still run old versions of an operating system, browser or application. Turn on automatic updates where possible and remove software you no longer use.

## Backups

Keep backups using the 3-2-1 rule: three copies of your data, on two different types of storage, with one copy kept offsite or offline. Backups protect against ransomware, hardware failure and accidental deletion. A backup that has never been restored is only a hope, so test a restore from time to time.

## Safe networks

Public Wi-Fi networks can be monitored or imitated by attackers. Prefer your own mobile data for sensitive tasks, make sure websites use HTTPS, and use a trusted VPN if you must work on a public network. At home, change the default router password and use WPA3 or WPA2 encryption.

## Least privilege

The principle of least privilege means that every user and program receives only the access needed for its job. Use a standard account for daily work instead of an administrator account, and remove access when someone changes roles or leaves a project.

## Reporting incidents

If you suspect that an account or device is compromised, act quickly: disconnect the device from the network, change passwords from a clean device, enable MFA and tell the responsible team. Reporting early limits the damage and helps others avoid the same attack.
